1부 · 구글 시트와 서버 (약 30분)

  1. 구글 드라이브 → 새로 만들기 → 스프레드시트. 주소창의 긴 글자(시트 ID)를 복사해 둡니다.
  2. 그 시트에서 확장 프로그램 → Apps Script.
    왼쪽 Code.gs 클릭 → Ctrl+A → Delete → 받으신 Code.gs 를 전부 붙여넣기 → Ctrl+S
  3. Ctrl+F 로 SPREADSHEET_ID 를 찾아 작은따옴표 안을 내 시트 ID 로 바꾸고 Ctrl+S
  4. 위쪽 함수 칸에서 새시트만들기 를 골라 ▶ 실행
    → 권한 창이 뜨면 고급 → 이동 → 허용
    (「확인되지 않은 앱」 은 정상입니다)
  5. 생긴 학교설정 탭에서 학년 · 반 수 · 한 반 학생 수 · 과목 이름 을 우리 학교에 맞게 고칩니다. 과목은 1학기·2학기를 따로 한 줄씩.
    ⭐ 1학기 총원 · 2학기 총원 = 석차를 낼 때 나누는 수 (예: 191 · 193). 비우면 시험 본 학생 수를 저절로 셉니다. 전학생이 오면 그 학기 칸만 고칩니다.
  6. 새시트만들기 를 한 번 더 실행 → 나머지 탭이 전부 생깁니다.
    (있는 탭은 절대 안 건드립니다)
  7. 내신성적 탭에 이름과 1차시험·2차시험·1차수행·2차수행 을 넣습니다.
    이름은 여기에만 — 다른 탭에 저절로 따라갑니다. 등급·환산총점·성취도· 상담_계산·상담_2차목표는 수식이라 저절로. 학생 없는 줄은 비워 두세요.
  8. 배포 → 새 배포 → ⚙ → 웹 앱
    실행 대상 나 / 액세스 권한 모든 사용자 → 배포
    → 나오는 웹 앱 URL(.../exec)을 적어 둡니다
  9. 시트로 돌아가 F5 → 상단 🔐 상담시스템 관리 에서 계정을 만들고 승인하면 비밀번호가 나옵니다.
액세스 권한이 「모든 사용자」라서 불안하신가요?
비밀번호 화면이 앞을 막고 있어 안전합니다. 로그인하지 않으면 아무 자료도 나가지 않습니다.

2부 · 화면 만들기 (약 15분)

  1. github.com → Sign up (무료)
  2. 오른쪽 위 + → New repository
    이름은 영어로 아무거나(예: sangdam), Public → Create repository
    Public 이어도 성적은 안 올라갑니다 (화면 뼈대만).
  3. 받으신 index.html 을 메모장으로 열고 23번째 줄을 찾습니다.
    const API_URL = '여기에_붙여넣으세요';
    작은따옴표 안을 1부 8번의 웹 앱 주소 로 바꾸고 저장.
  4. 저장소에서 Add file → Upload files → 고친 index.html 을 끌어다 놓고 Commit changes
  5. Settings → Pages → Source Deploy from a branch · Branch main / /(root) → Save
  6. 1~2분 뒤 나오는 주소가 내 사이트입니다.
    https://내아이디.github.io/sangdam/
  7. 사이트에서 🔧 연결 상태 확인 을 눌러 초록색이면 끝. 1부 9번의 비밀번호로 로그인합니다.
